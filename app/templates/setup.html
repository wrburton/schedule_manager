Setup required

Google Calendar credentials need to be configured. On the server, in ~/share/schedule_manager:

  1. Create OAuth credentials (a desktop app) in Google Cloud Console.
  2. Set GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET in .env.
  3. Run venv/bin/python scripts/get_token.py.
  4. Copy the GOOGLE_REFRESH_TOKEN it prints into .env.
  5. Restart the app: srv restart calendar.

The README has the details.
